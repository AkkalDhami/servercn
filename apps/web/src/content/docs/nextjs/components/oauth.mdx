## Environment Variables

Configure each provider in your <Code>.env</Code> file:

#### Next Auth

```dotenv title=".env"
NEXTAUTH_URL=
NEXTAUTH_SECRET=
```

#### Google

```dotenv title=".env"
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
```

#### GitHub

```dotenv title=".env"
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=
```
